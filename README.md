# Proyek Laboratorium JavaScript ES6

## Latar Belakang

Perkembangan JavaScript sebagai bahasa pemrograman utama dalam pengembangan web mendorong munculnya standar baru, yaitu ECMAScript 6 (ES6). Standar ini dirancang untuk mengatasi keterbatasan ES5, khususnya dalam aspek keterbacaan kode, pengelolaan variabel, serta efisiensi penulisan fungsi. Oleh karena itu, pemahaman terhadap fitur ES6 menjadi penting dalam konteks pengembangan perangkat lunak modern.

## Rumusan Masalah

Permasalahan dalam proyek ini berfokus pada:

1. Bagaimana mengonversi sintaks ES5 ke ES6 secara sistematis
2. Bagaimana penerapan fitur ES6 dapat meningkatkan kualitas kode
3. Bagaimana implementasi ES6 memengaruhi keterbacaan dan pemeliharaan program

## Tujuan

Tujuan dari proyek ini adalah:

* Mengidentifikasi perbedaan utama antara ES5 dan ES6
* Menerapkan fitur ES6 dalam kode JavaScript
* Mengevaluasi dampak penggunaan ES6 terhadap struktur program

## Metodologi

Pendekatan yang digunakan bersifat eksperimental dengan tahapan sebagai berikut:

1. Membuat struktur proyek berbasis HTML dan JavaScript
2. Mengidentifikasi penggunaan sintaks ES5
3. Melakukan refactoring kode ke ES6
4. Menguji hasil melalui console browser

## Implementasi

### 1. Penyiapan Proyek

Struktur dasar proyek terdiri dari file HTML dan JavaScript yang saling terhubung untuk memungkinkan pengujian langsung di browser.

### 2. Konversi Variabel

Penggunaan `var` digantikan dengan `let` dan `const` untuk meningkatkan kontrol terhadap scope variabel. Hal ini mengurangi risiko kesalahan akibat hoisting dan redeklarasi.

### 3. Arrow Function

Fungsi tradisional diubah menjadi arrow function untuk menghasilkan sintaks yang lebih ringkas dan konsisten, terutama dalam penulisan fungsi sederhana.

### 4. Template Literals

Template literals digunakan untuk menggantikan penggabungan string konvensional, sehingga meningkatkan keterbacaan dan fleksibilitas dalam penyisipan variabel.

### 5. Fitur ES6 Modern

Implementasi fitur tambahan meliputi:

* Destructuring untuk ekstraksi data dari objek
* Spread operator untuk manipulasi array
* Default parameter untuk meningkatkan fleksibilitas fungsi

## Hasil dan Pembahasan

Hasil implementasi menunjukkan bahwa penggunaan ES6 menghasilkan kode yang lebih terstruktur dan mudah dipahami. Penggunaan `const` dan `let` memberikan batasan yang jelas terhadap perubahan data, sementara arrow function menyederhanakan penulisan fungsi. Selain itu, template literals dan destructuring secara signifikan meningkatkan efisiensi penulisan kode.

## Kesimpulan

Transformasi dari ES5 ke ES6 memberikan dampak positif terhadap kualitas kode, terutama dalam aspek keterbacaan, efisiensi, dan pemeliharaan. Dengan demikian, penggunaan ES6 dapat dianggap sebagai praktik standar dalam pengembangan JavaScript modern.
